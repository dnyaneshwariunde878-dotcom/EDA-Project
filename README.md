# Exploratory Data Analysis (EDA)

## Objective
To analyze a dataset and identify trends, patterns,
missing values, duplicates, and outliers.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Steps
1. Load the dataset.
2. Explore rows, columns, and data types.
3. Check missing values and duplicates.
4. Generate histograms and correlation heatmaps.
5. Test hypotheses and summarize findings.

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the program:

python eda_analysis.py# EDA-Project
